# 🌟 生活小助手 (Daily Life Assistant)

一个轻量级、极简风格的纯前端生活辅助 Web 应用。旨在为用户提供快速、无广告的日常实用小工具合集。

## 🌍 在线预览
**Demo 演示地址：** [https://cf-worker-dir-bke.pages.dev](https://cf-worker-dir-bke.pages.dev)

## ✨ 核心功能
*   **极简主页**：清爽的 UI 设计，拒绝任何多余的视觉干扰。
*   **快速响应**：采用原生纯净的前端代码构建，无繁重框架，秒级加载。
*   **跨平台适配**：完美兼容 PC 端与移动端浏览器（Responsive Design）。
*   **边缘网络部署**：依托全球分布式边缘网络架构，保障各地访问延迟最低。

## 🚀 部署指南

本项目原生支持在各大 Serverless / Edge 平台一键部署（如 Cloudflare Pages, Vercel, Netlify）。

### 通过 Cloudflare Pages 部署 (推荐)
1. Fork 本仓库到你的个人 GitHub 账号。
2. 登录 [Cloudflare 控制台](https://dash.cloudflare.com/)，进入 `Workers & Pages`。
3. 点击 `Create application` -> `Pages` -> `Connect to Git`。
4. 选择你刚刚 Fork 的仓库。
5. 构建设置 (Build Settings) 保持默认空值即可。
6. 点击 `Save and Deploy`，等待 1 分钟即可完成上线！
